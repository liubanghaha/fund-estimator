# H5 add-holding 页面重构方案

参考 master 分支小程序 add-holding 页面，重构 H5 新增/编辑持仓流程。

## 改动文件

### 1. `web/src/api/index.ts` — 新增 `holding.add` 方法

```ts
holding.add: (data) => callFunction('manageHolding', withUid({ action: 'add', data }))
```
云函数 `manageHolding` 已有 `add` case，只需补充客户端调用。

### 2. `web/src/pages/add-holding/index.tsx` — 全面重写

#### 新增表单字段（对齐 master）
- **基金名称** — 手动输入框 + "查询"按钮（调用 fetchFundInfo 自动填名）
- **买入日期** — `<input type="date">` 日期选择
- **所属分组** — 分组下拉选择器（可新建分组）

#### 编辑模式增强
- 加载已有持仓时，调用 `fetchFundEstimate` 获取最新净值，**重算 marketValue 和 holdingReturn**（与详情页一致）
- **加减仓** — 输入调整金额（+/- 切换），选交易日期和备注，保存时创建 transaction 记录，更新 shares/buyPrice/marketValue
- **删除按钮** — 确认后调用 holding.remove + 清理关联交易记录

#### 保存流程改进（对齐 master 的 onSubmit）
**新增持仓：**
1. 校验必填字段
2. 调用 `fetchFundEstimate` 获取当前净值
3. 计算 `shares = marketValue / nav`、`buyPrice = nav - holdingReturn / shares`、`buyAmount = shares * buyPrice`
4. 调用 `holding.add({ fundCode, fundName, buyPrice, shares, marketValue, holdingReturn, buyAmount, buyDate, group })`
5. 自动加入自选 `watchlist.add`
6. 清除缓存，跳转首页

**编辑持仓：**
1. 如有加减仓金额 → 计算买卖份额 → 创建 transaction 记录 → 更新 shares/buyPrice/marketValue
2. 否则直接更新字段
3. 调用 `holding.update(id, data)`
4. 清除缓存，返回上一页

#### UI 布局
- 代码输入框 + 查询按钮（编辑时禁用）
- 名称输入框
- 持有金额、持有收益（+/- 切换）、买入日期、所属分组
- 编辑模式额外显示：加减仓金额（+/- 切换）、交易日期、备注
- 保存按钮 + 编辑模式删除按钮

- 批量导入
