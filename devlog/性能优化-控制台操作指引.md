# 性能优化 · 控制台操作指引

代码层面的性能优化已完成，以下两步需要到 **腾讯云开发控制台**（https://tcb.cloud.tencent.com）手动操作。

## 1. 数据库索引（建议尽快建）

进入：云开发控制台 → 数据库 → 对应集合 → 索引管理 → 新建索引

| 集合 | 索引字段 | 类型 | 解决什么问题 |
|---|---|---|---|
| `fund_temperatures` | `fundCode` + `date` | 组合索引（升序/升序） | getPortfolio / computeFundTemperature 每日按基金+日期查温度（高频） |
| `fund_temperatures` | `fundCode` + `createTime` | 组合索引（升序/降序） | computeFundTemperature 持仓缓存读取（orderBy createTime desc） |
| `profit_snapshots` | `_openid` + `date` | 组合索引 | snapshotProfit / getPortfolio / portfolioLight 按用户+日期查快照（每分钟高频） |
| `transactions` | `_openid` + `createTime` | 组合索引（升序/降序） | 交易记录分页排序（manageTransaction orderBy） |
| `holdings` | `_openid` + `fundCode` | 组合索引 | 持仓查询/去重 |

> 说明：云开发数据库复合查询（where 多字段 + orderBy 排序）缺索引时可能直接报错或退化为全表扫描，建议全部创建。

## 2. 云函数预置并发（可选，约几元/月）

消除"长时间未使用后的冷启动"（首次调用 1-3 秒延迟）：

进入：云开发控制台 → 云函数 → `getPortfolio` → 配置 → 预置并发 → 设为 `1`

**建议预置的函数**（用户请求路径上的热点函数）：

| 函数 | 预置并发 | 说明 |
|---|---|---|
| `getPortfolio` | 1 | 首页/收益走势/资产分析核心入口，冷启动影响最大 |
| `batchFetchEstimate` | 1 | 自选列表每次刷新 |
| `portfolioLight` | 1 | 首页/收益走势盘中轮询（15-30 秒一次） |

> 预置并发按"预留的实例数 × 时长"计费，1 个实例约几元/月；不预置也能用（每次冷启动慢 1-3 秒）。

## 3. 可选：清理历史快照数据

`profit_snapshots` 按天分文档（`_openid + date`），每天约 16KB/用户，一年约 4MB/用户。数据量大的话可以在控制台定期清理 30 天前的快照文档，或忽略（当前量级无影响）。
