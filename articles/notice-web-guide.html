关于小程序与网页版的使用说明

2026年8月7日 · 韭菜养基宝

各位基友：

这篇是把「现在怎么用」一次说清楚——网页版怎么登录、账本怎么记，还有接下来我们要做的事。

一、现在怎么用

微信小程序（理财笔记）记账、持仓记录、关注自选 —— 日常记录用小程序
网页版（仓记小簿）基金搜索、实时估值、详情分析、收益走势、对比、截图加减仓、资产分析 —— 深度分析用网页版

两边是同一个账号、数据实时同步。小程序记的账，网页版马上能看到；网页版做的分析，也不影响小程序里的记录。

二、为什么有网页版？

微信对小程序的功能审核比较严，基金搜索、详情分析、截图识别这类功能，在目前的小程序主体下无法上架。为了不让功能被砍掉，我们把这些功能做成了网页版。

所以现在：小程序 + 网页版 = 完整功能。两边配合用，体验和之前一样完整。

三、网页版怎么用（三步）

第一步：打开网页版
fundleek.com

手机浏览器输入上面地址即可。建议「添加到手机桌面」：Safari 点分享 → 添加到主屏幕；安卓 Chrome 点菜单 → 添加到主屏幕。之后像 APP 一样一点就开。

第二步：登录小程序，复制账号 ID

打开小程序 → 如还未登录，先点「一键登录」完成登录 → 底部「我的」→ 点「网页版登录」→ 点击账号 ID，即复制成功。

第三步：粘贴账号 ID 登录

回到网页版 → 粘贴刚复制的账号 ID → 点登录。你的持仓、账本、自选会自动同步，不用重新注册。

账号 ID 就是你的登录凭证，认账号不认设备。换手机、换浏览器，登录同一个账号 ID，数据都在。

四、网页版能做什么？

基金搜索输入 6 位代码快速查找
基金详情实时估值、历史净值、基金档案、持仓分析、费用黑洞
收益走势每日收益日历、收益走势图、大盘分时
基金对比两只基金净值走势对比
截图加减仓截图识别持仓，自动调整账本
资产分析组合健康分、持仓穿透、基金重合度
历史数据导入导入过往交易记录

五、账本功能（小程序里直接记）

小程序底部「我的账本」就是你的记账本：

记录投入/卖出每笔操作记一笔，自动汇总持仓市值与收益
分组管理按「定投」「白酒」「债基」等自定义分组
实时估值盘中打开即看当日涨跌估算

没有的基金直接在小程序里「添加持仓」输入代码和金额即可。

六、好消息：全功能小程序正在路上

之前因为审核限制被搬到网页版的功能——基金搜索、详情分析、收益走势、对比、截图加减仓、资产分析——正在准备全部放回小程序，以后一个小程序就能搞定所有事。

正式上线之前，先用好现在的搭配：小程序记账，网页版分析。
